# Exact-command production validation

`scripts/caddy_readonly_validator.py` is the canonical fixed-target validator for the production Caddy container `codestra-caddy` (see `docs/PRODUCTION_RUNTIME.md`). It accepts no arguments and invokes only fixed, read-only commands: `docker inspect` and `docker image inspect` for the container and image identity, `docker cp` of `/etc/caddy` for the configuration identity, `docker exec` of `caddy validate`, `caddy adapt` and `caddy list-modules`, `docker top` and `ss` for listener ownership, and `curl` of the private `/healthz`. It reads the served configuration over the private admin socket and emits sanitized structural JSON rather than raw configuration or runtime values.

It fails closed when the container is not running and healthy, the image is not the digest-pinned canonical identity, its labels or non-root user disagree, the running `/etc/caddy` tree does not match the signed configuration digest, a runtime value is missing or malformed, required Authorization/API-key log deletion is missing, the served configuration differs from the image's configuration, a listener is not owned by the single Caddy process, or an upstream cannot be represented as a plain host and optional port.

This repository change does not install the validator, modify SSH, grant sudo, or authorize reload. Installation requires a separately reviewed protected release that pins the file checksum and exposes exactly this no-argument command through the existing bounded operator. Evidence storage must be root-owned mode `0600`.
